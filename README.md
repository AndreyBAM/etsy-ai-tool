# Etsy Extension — Core Prototype

Первый рабочий прототип "ядра" из плана (раздел 6 и 13): генерация
продающего английского текста листинга из описания продавца на родном
языке — платформо-независимая часть, готовая для интеграции в
расширение или для быстрого теста качества до старта разработки UI.

## Архитектура (почему так)

```
src/
  core/                      ← платформо-независимо, НЕ ЗНАЕТ про Etsy/eBay
    promptBuilder.js         ← собирает system+user промпт
    marketplaceProfiles.js   ← единственное место со спецификой площадки
    generateListing.js       ← вызывает Claude API, парсит JSON-ответ

  adapters/                  ← платформо-зависимо, знает про конкретный DOM
    PlatformAdapter.js       ← абстрактный контракт (интерфейс)
    etsyAdapter.js            ← реализация под Etsy (селекторы — ЗАГОТОВКА,
                                 см. TODO внутри файла, доработать после
                                 первого реального теста на живой странице)

  server/
    server.js                 ← backend-прокси: держит API-ключ на сервере,
                                 расширению отдаёт только готовый JSON
```

**Почему разделено именно так:** `core/` можно тестировать и улучшать прямо
сейчас, независимо от того, разрешат ли постить в Telegram-группе продавцов
и как выглядит вёрстка Etsy. `adapters/` — единственное, что придётся
переписывать при смене/добавлении площадки (eBay и т.п.) или если Etsy
обновит интерфейс редактора. Добавление новой площадки в будущем = новый
файл в `adapters/` + одна запись в `marketplaceProfiles.js`, без изменений
в `core/`.

## Быстрый старт

```bash
npm install       # зависимостей нет, но команда безопасна
cp .env.example .env
# впишите свой ключ с console.anthropic.com в .env

# Вариант 1: быстрый тест ядра без сервера (для валидации качества,
# см. раздел 11 плана — прогнать 10 украинских листингов вручную)
ANTHROPIC_API_KEY=sk-ant-... node test-cli.js "Кулон з натурального бурштину ручної роботи, підходить для подарунку"

# Вариант 2: поднять backend-прокси (то, к чему потом будет обращаться расширение)
ANTHROPIC_API_KEY=sk-ant-... npm run server
# затем:
curl -X POST http://localhost:3000/api/generate \
  -H "Content-Type: application/json" \
  -d '{"rawText": "Кулон з натурального бурштину ручної роботи", "sourceLang": "uk"}'
```
